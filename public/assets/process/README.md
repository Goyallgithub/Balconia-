# Makeover journey imagery

Created using the built-in image-generation tool. Marketing examples, not customer installation records.

- balcony-before-v1.webp: derive an empty raw balcony from the Chai Club reference; retain walls, railing, doorway, tiles, skyline and camera. Remove styling; include measuring tape, drain and socket. Photorealistic survey-photo style.
- balcony-after-v1.webp: style that exact raw balcony using the Chai Club reference, preserving architecture and view. Add matching bistro set, rug, greenery, planter stand and warm lights. Remove tape measure. Photorealistic finish.

The product-plan collage uses the existing catalogue photos for FUR-001, DEC-010, P002, L014 and C1 rather than inventing new product imagery.
Generated source PNGs were retained in the generation output; full-resolution WebP copies at quality 95 are used on the website.
